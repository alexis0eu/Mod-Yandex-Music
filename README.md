# Яндекс Музыка Мод (Версия 5.124.1)

Мод для официального десктопного клиента Яндекс Музыки (актуальная версия 5.124.1), созданный исключительно в познавательных и образовательных целях для личного использования.

---

## 🌟 Ключевые возможности

### 1. 🎮 Steam / Discord стиль Игровой Оверлей (Killer Feature)
- Плавающий полупрозрачный HUD-плеер поверх всех окон и игр с эффектом матового стекла (Frosted Glassmorphism).
- **Хоткей вызова:** `Ctrl+Shift+O`.
- **Сквозной режим (Ghost Mode):** хоткей `Ctrl+Shift+G` или переключатель в оверлее. В сквозном режиме клики проходят сквозь оверлей прямо в окно игры; при наведении курсора на интерфейс карточки элементы становятся активными для управления.
- **Управление треками:** обложка с динамической подсветкой в акцентный цвет, анимация эквалайзера, бегущая строка названия и артиста, кликабельный прогресс-бар с перемоткой, кнопки Next / Prev / Play / Pause / Like.
- **Интеграция с нативным плеером:** поддерживает как прямое управление через React Fiber, так и диспетчеризацию через нативный IPC канал `desktop:player:action`.

### 2. 🎤 Плавающее Экранное Караоке (Killer Feature)
- Плавающая строка текста поверх игр и приложений с автоматической подсветкой активной строки (Karaoke Glow) и плавной авто-прокруткой.
- **Хоткей вызова:** `Ctrl+Shift+L`.
- Полный сквозной режим по умолчанию (не перехватывает клики мыши во время гейминга).
- **Реальный резолвер синхронных текстов:** автоматическое получение официальных таймкодов Яндекс Музыки (`/tracks/{id}/supplement`) с резервным авто-поиском через базу синхронных текстов LRCLib API.
- Корректная плавная раскладка для треков без встроенных LRC-таймкодов.

### 3. 🎨 Дизайн и Переключатель Внешнего Вида
- **Выбор стиля дизайна:** проверенный классический (Старый дизайн) или обновленный (Моя Волна Redesign) через перехват `account/experiments/details`.
- **Акцентные цвета темы:** Neon Blue (`#007acc`), Emerald Green (`#10b981`), Crimson Red (`#ef4444`), Purple Dream (`#8b5cf6`), Cyberpunk Gold (`#f59e0b`), Vapor Pink (`#ec4899`) или произвольный HEX-пикер.
- Градиентная подсветка фона плеера под выбранный цвет.
- Возможность отключить тяжелую фоновую анимацию «Моя Волна» для экономии CPU/GPU в играх.

### 4. 🔤 Настройка шрифтов
- Замена шрифта интерфейса во всем приложении на лету.
- Встроенные шрифты:
  - `JetBrains Mono` (код-стиль)
  - `Minecraft` (пиксельный ретро-шрифт)
  - `Terraria / Andy Bold` (мультяшный рукописный)
  - `Inter` (современный чистый интерфейс)
  - `Segoe UI`, `Roboto`
  - Поле ввода для любого установленного системного шрифта Windows.

### 5. ⚡ Дополнительные инструменты и твики
- **Discord Rich Presence (RPC):** встроенный легковесный клиент на чистом Node.js (работает через именованный пайп Discord IPC, отображает обложку, трек, таймкод и кнопку «Слушать в Яндекс Музыке»).
- **Режим разработчика:** хоткеи `F12` и `Ctrl+Shift+I` для вызова DevTools на любом окне.
- **Авто-выбор максимального качества:** автоматическая установка качества потока 320 kbps / FLAC Lossless.
- **Масштаб интерфейса (UI Zoom):** выбор масштабирования (85%, 90%, 100%, 110%, 120%) для комфортного отображения на 2K/4K мониторах.
- **Блокировка рекламы и телеметрии:** отключение `adsdk.js`, Яндекс.Метрики и стриминговых трекеров.

## 🚀 Управление модом

### Внедрение / Обновление мода:
```powershell
python tools\inject.py
```
*Скрипт автоматически создает резервные копии `app.asar.bak` и `Яндекс Музыка.exe.bak`, патчит ASAR с изоляцией окон, обновляет заголовочный SHA256 хеш целостности в исполняемом файле и настраивает Electron Fuses.*

### Откат к оригиналу (удаление мода):
```powershell
python tools\restore.py
```

### Запуск верификационных тестов:
```powershell
python tools\verify.py
```

## ⌨️ Горячие клавиши в приложении
- **`Ctrl + Shift + O`** — Показать / скрыть Steam Gaming Overlay
- **`Ctrl + Shift + G`** — Включить / выключить сквозной клик (Ghost mode) оверлея
- **`Ctrl + Shift + L`** — Показать / скрыть Плавающее Караоке с текстом песни
- **`Ctrl + Shift + I` / `F12`** — Открыть инструменты разработчика (DevTools)
